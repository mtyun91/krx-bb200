# 2026-11-05 대응 중심 개선

이번 변경은 오류 수정과 **비교 가능한 전략 후보** 추가다. 새 전략의 수익성은 아직 실데이터로 입증하지 않았다. 기존 사용자 설정·계좌·키는 변경하지 않았다.

## 사용 순서

1. 프로그램을 새로고침한다.
2. 백테스트 → 내 매매 규칙 → **하락·수축·추세 대응 비교**를 누른다. 현재 설정과 네 후보를 비교한다. 비교만으로 현재 설정이 바뀌지 않는다.
3. 비서 탭의 **진입 가격·휩소 대응**에서 5일선 거리, 돌파봉 저가까지 손실 폭, 120일 전고점, 전날 OBV·CMF 근거를 확인한다.
4. 중계기에 연결한 상태에서 **5분봉 갱신·진입 점검**을 누른다. 분봉 실행을 필수로 하려면 설정의 **모의 매수에 5분봉 지지·재상승 확인 필수**를 켠다.
5. 일봉에서 Shift+드래그로 진입~청산을 표시하고 👍/👎와 이유를 저장한다. 비서의 **매매 스타일 학습**에서 진입·청산 각각의 유사 예시를 확인한다. **예시에서 매수 규칙 뽑기**는 규칙 초안을 비교한 뒤 선택 적용한다.

## 매매의 의미

- 일봉: 기존 수축 조건에 선택적으로 **고점→하락→최근 120일 횡보의 순서**와 **20일 전보다 상단 하락·하단 상승**을 확인한다. 매집·전고점 우회 경로를 끈 비교 후보를 제공한다.
- 진입: 돌파 당일 외에 설정한 1~5일 안의 5일선 지지 반등도 후보로 볼 수 있다. 원 돌파봉 저가 아래 종가가 발생한 후보는 제외한다.
- 분봉: 오늘 확정 5분봉 4개 이상, 최근 봉의 전고점 돌파·저점 상승, 당일 거래량 가중 평균 위를 확인한다. 조용한 상승도 가능하도록 거래량 급증을 필수 조건으로 두지 않는다. 거래량 0·과거 세션·오래된 자료·미완성 봉은 통과시키지 않는다.
- **거리 위험 점수** = 현재가에서 5일선까지 하락폭(%) × 10, 최대 100. 낮을수록 기준선까지 거리가 짧다는 뜻이며 상승 확률이 아니다. 5일선이 현재가 위면 낮은 위험 점수로 오인하지 않도록 산정 불가로 표시한다.
- 5일선은 진입 가격 기준이다. 실제 손절이 돌파봉 저가라면 그 선까지의 손실 폭은 별도로 봐야 한다.
- 추세 손절: 돌파봉 저가에서 시작해 좌우 두 봉으로 확인된 높아진 저점을 따라간다. 오늘의 미완성 봉으로 저점을 확정하지 않고 손절선을 낮추지 않는다.
- 휩소 대응: 이동평균 이탈 1~3개 봉 확인, 초기 0~3개 봉 유예를 선택한다. 확인 2개 이상이면 장중 오늘 봉을 확정 종가로 세지 않는다. 구조 손절은 유예되지 않는다. 기존 운용 시간대가 15:00~15:20이므로 종가 확인이 필요한 판단은 다음 운용 시간대에 이뤄질 수 있다.
- 손실 한도: 진입 시 평가자산 대비 종목별·전략 포트폴리오 합계 계획 손실을 제한한다. 구조 손절 거리와 비용으로 수량을 계산하며, 추가 매수용 위험 예산도 예약한다. 수동 장부·인버스·실계좌를 포괄하는 전체 계좌 한도는 아니다. 갭이나 체결 지연으로 실제 손실은 초과할 수 있다.
- 당일 진입/눌림 문구는 전고점·거리로 분류하는 설명용 휴리스틱이다. 수급 수치는 매집 증거의 일부이며 매집 여부나 진짜 상승을 확정하지 않는다.

## 수정한 오류

- 추가 매수보다 손절·매도 판단을 우선한다. 같은 일봉에 익절 고가와 청산 조건이 함께 있으면 청산을 먼저 반영하는 보수적 가정으로 변경했다.
- 체결 수량이 0이면 매수 단계가 넘어가지 않는다. 1차 비중 0인 빈 포지션도 만들지 않는다.
- 결재 모드의 승인 없는 추가 매수를 차단했다. 추가 매수는 현재 별도 수동 주문으로 해야 한다.
- 거래일 누락 종목의 계좌 평가에 원가 대신 직전 평가가를 쓴다.
- 제안 수량과 실행 수량 모두 같은 손절 거리·위험 예산 계산을 쓴다.
- 고정된 옛 전략 승률을 모든 새 전략의 결재 설명에 표시하던 문구를 제거했다.
- 드래그 선호와 거래 수익 여부를 분리했다. 선호 예시를 수익 확률의 정답으로 섞지 않는다.
- 수익 모델은 진입일로 시간 분할하고 검증 시작 전에 종료되지 않은 학습 거래를 제외한다. 구형 모델과 구분력 부족 모델은 예측하지 않는다.
- 유사 자리 성과는 표시일 전에 결과까지 확정된 자료만 쓴다. 일봉 학습에 분봉의 미래 일봉 종가가 섞이지 않도록 분봉 표시는 학습에서 제외한다.
- 표시한 구간의 전략 청산 비교도 공통 전략 엔진으로 계산한다.

## 검증과 남은 범위

- `node tools/test_strategy.cjs`: 18개 회귀 테스트 통과. 구조 손절·위험 수량·결재 우회·미래 정보·눌림 유효기간·분봉 신선도 등을 검사했다.
- 전체 화면 스크립트 문법 검사 통과.
- 별도 브라우저·가상 일봉으로 화면 실행 오류 없음, 현재 설정+4개 비교, 비교 후 설정 복원, 드래그 진입·청산 문맥 저장을 확인했다. 사용자 중계기·저장 계좌와 연결하지 않았다.
- 새 조건의 실제 시장 수익성, 장중 체결, 슬리피지, 거래량 공급자의 봉 시각 정의는 아직 검증하지 않았다. 분봉은 시작 시각 기준으로 보수적으로 확정 판단한다.
- 일봉 백테스트는 5분봉 실행 필터를 재현하지 않는다. 화면에 이를 표시한다. 분봉 포함 성과 검증에는 해당 기간의 분봉 자료가 필요하다.
- 비교 버튼은 학습한 예시와 완전히 독립된 검증이 아니다. 예시로 만든 규칙의 과거 재현과 이후 신규 사례 검증을 구분해야 한다.
- 청산 예시는 유사 상황 비교와 AI 설명에 반영되며, 자동 청산 규칙 학습·적용은 아직 제공하지 않는다. 진입 규칙 후보는 기존 추출·비교·적용 흐름을 사용한다.
- 다음 작업은 사용자가 지정한 선호 진입과 너무 빠른 손절 사례로 오탐·누락을 확인하고, 분봉 재생 검증을 추가하는 것이다.
