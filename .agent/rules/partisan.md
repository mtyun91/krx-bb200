# 파르티잔 인베스트먼트 — 항상 지킬 규칙

작업 전에 프로젝트 루트의 `GEMINI.md`를 읽는다. 아래는 그중 꼭 지킬 것만 추린 것이다.

- 사용자에게 보이는 모든 글(답변·화면·버튼·음성)은 한국어로 짧고 쉽게. 프로그램 용어·명령 글자가 화면에 보이거나 읽히지 않게.
- 나무 앱키·시크릿·계좌번호는 사용자만 실행기에 입력한다. 저장·출력·대신 입력 금지. 백업·동기화·git에도 넣지 않는다.
- AI는 실제 주문을 넣지 않는다. 실계좌 주문은 매번 사용자 클릭 확인(realSubmit)으로만, 한도·정지는 실행기·중계기가 관리.
- 종목을 추천하지 않는다. 결정은 사용자 — 결재제(모의 자동매매는 사용자 결재 없이 실행 안 함, 리스크 브리핑 읽음 체크 필수)를 약하게 만들지 않는다. 비서·위젯은 대신 결재할 수 없다.
- 사용자가 쓰는 중계기(127.0.0.1:8766)는 끄거나 재시작하지 않는다. 시험은 다른 포트의 데모 중계기(`BRIDGE_PORT=8767 python nh_bridge.py --demo`)와 별도 브라우저 출처에서, 끝나면 시험 기록을 되돌린다.
- `krx_state.json`(사용자 계좌·설정)은 함부로 고치지 않는다.
- 작업을 마칠 때마다 한국어 커밋 메시지로 커밋하고 `git push`. 화면 버전은 pre-commit 훅이 자동으로 올린다(손대지 말 것). 저장소는 비공개 유지.
- 신호 로직은 백테스트·모의투자·차트·알림이 같은 함수(`isBreakout` 계열)를 쓴다. 새 설정은 `DEFAULTS`+`SETTING_DEFS`, 동기화 상태는 `syncPayload`·`applySynced`·`saveStore`에 함께.
- 코드를 많이 고친 뒤에는 `python tools/make_handoff.py`로 `docs/CODE_MAP.md`를 다시 만든다.
