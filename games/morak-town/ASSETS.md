# 모락모락 타운 그래픽 에셋 명세서

전체 디자인을 이미지 에셋으로 다시 만들기 위한 목록과 제작 규칙이다. 지금 게임은 모든 그림을 코드로 그린다. 이미지 에셋이 들어오면 엔진이 이미지를 우선 쓰고, 없는 것만 지금의 코드 그림으로 대신 그린다. 그래서 일부만 먼저 준비해도 바로 적용할 수 있다.

승인된 그림체 기준은 사용자가 만든 상황별 시안 6장(봄 아침·비 오는 저녁·여름 해변·가을 시장·겨울 야경·점심 매장 단면)이다.

## 1. 모든 이미지에 공통으로 지킬 규칙

### 1-1. 시점과 크기
| 항목 | 규칙 |
| --- | --- |
| 투영 | 2:1 아이소메트릭(가로 2 : 세로 1 마름모). 원근 없음. 모든 에셋이 같은 각도 |
| 도시 1칸 | 마름모 **가로 128px × 세로 64px** (게임 화면 기준의 2배 해상도로 제작) |
| 매장 안 1칸 | 마름모 **가로 64px × 세로 32px** (매장 안 1칸 = 실제 약 50cm) |
| 도시 사람 | 서 있는 어른 키 약 **34px**, 아이 약 24px |
| 매장 안 사람 | 서 있는 어른 키 약 **96px**, 앉은 어른 약 70px |
| 파일 | **PNG, 배경 투명**. 투명이 어려우면 단색 마젠타(#FF00FF) 배경으로 주면 제가 지움 |
| 여백 | 그림 둘레 투명 여백은 4px 이하(그림자 포함) |

### 1-2. 선과 색
- 외곽선: 진한 적갈색 **#6B2427**. 굵기 3단계(2배 해상도 기준): 건물·큰 물체 외곽 3px, 구조선 2px, 작은 디테일 1px. 선 끝은 둥글게.
- 색: 납작한 색면, 면 방향에 따라 2~3단계 명암만. 그라데이션·광택·사실적 질감·번짐 없음.
- 기본 팔레트(시안 기준 시작값): 크림 #F7EDCE · 머스터드 #DFB964 · 코랄 #D96D60 · 더스티 핑크 #CC7998 · 라벤더 #A497C3 · 올리브 #999D70 · 청록 #39AFAD · 잔디 #B9CF7C · 포장 #F6E7DF
- 빛은 왼쪽 위에서. 왼쪽 앞면이 밝고 오른쪽 앞면이 한 단계 어둡다.
- **그림자는 이미지에 넣지 않는다.** 바닥 그림자는 엔진이 그린다. 물체 자체의 면 명암만 넣는다.
- **글자(간판 상호)는 이미지에 넣지 않는다.** 빈 간판 판만 그린다. 상호는 엔진이 매장마다 써 넣는다.

### 1-3. 기준점(가장 중요)
엔진이 이미지를 정확한 칸에 세우려면 기준점이 정해져 있어야 한다.

- **바닥 물체(건물·가구·큰 소품):** 이미지의 **아래 가장자리 = 바닥 마름모의 아래(앞) 꼭짓점**, **왼쪽 가장자리 = 마름모의 왼쪽 꼭짓점**, **오른쪽 가장자리 = 마름모의 오른쪽 꼭짓점**. 그래서 이미지 가로 = (가로칸 + 세로칸) × 64px(도시) 또는 × 32px(매장 안)으로 딱 맞는다. 높이는 자유(지붕까지).
- **작은 소품·사람·차:** 이미지의 **아래 가운데 = 발(바퀴)이 땅에 닿는 점**.
- 각 이미지마다 발판 크기(예: 2×1)를 파일 이름에 적는다.

### 1-4. 방향
- 건물·매장: 정면이 **왼쪽 앞(L)** 을 보는 그림 1장. 엔진이 좌우로 뒤집어 오른쪽 앞(R)을 만든다(그래서 글자를 넣지 않음).
- 방향이 중요한 가구·차·사람: **4방향**(오른쪽 아래 SE, 왼쪽 아래 SW, 오른쪽 위 NE, 왼쪽 위 NW). SE와 SW만 주면 엔진이 뒤집어 나머지를 만든다. 뒷모습(NE·NW)이 앞모습과 달라야 하는 사람은 4방향 모두 필요.
- 둥근 테이블·화분처럼 방향이 상관없는 물체: 1장.

### 1-5. 겹쳐 쓰는 층(같은 크기·같은 기준점으로 따로 저장)
| 층 | 내용 | 쓰는 때 |
| --- | --- | --- |
| `_base` | 본체(낮) | 항상 |
| `_night` | 켜진 창문·간판 불빛 모양만(나머지 투명) | 밤에 위에 겹침 |
| `_snow` | 지붕·난간 위 눈만 | 겨울 |
| `_open` | 매장 앞 테라스·입간판·차양 펼친 모습 | 영업 중 |

### 1-6. 파일 이름과 폴더
```
assets/
  terrain/   road/   water/   building/   store/   landmark/
  prop/      tree/   vehicle/ people/     interior/ ui/  fx/
```
이름 규칙: `종류_이름_변형_발판_방향_층.png`
예: `building_townhouse_a_1x1_L_base.png`, `building_townhouse_a_1x1_L_night.png`, `interior_table4_wood_2x1_SE.png`, `people_adult_f01_walk_SE_sheet.png`

### 1-7. 애니메이션
- 가로로 나란히 붙인 한 장(스프라이트 시트). 프레임 크기를 모두 같게.
- 걷기 8프레임, 서 있기 2프레임(숨쉬기), 앉기 2프레임, 기타 동작 4~6프레임.
- 파일 이름에 프레임 수: `people_adult_m01_walk_SE_8f.png`

## 2. 우선순위
한 번에 다 만들 필요 없다. **1순위(기준 장면: 조개해변 구역)** 를 먼저 만들면 그 구역부터 새 그림으로 바꾸고, 나머지는 코드 그림으로 둔다.

| 순위 | 범위 | 대략 개수 |
| --- | --- | --- |
| 1순위 | 바닥·길·물, 저층 건물 8종, 매장 외관 5업종, 나무 4종, 거리 소품 20종, 사람 6명 걷기·앉기, 매장 안 기본 가구 20종, UI 아이콘 30개 | 약 150장 |
| 2순위 | 나머지 업종 외관, 건물 변형, 차량, 계절·밤·눈 층, 사람 동작 확장, 매장 스타일별 가구 | 약 250장 |
| 3순위 | 랜드마크 12곳, 행사(축제·시장), 날씨 효과, 고급 가구·장비 등급 | 약 150장 |

## 4. 이미지 생성 도구로 만들 때
- 한 장에 물체 하나. 시안 이미지를 스타일 기준으로 함께 넣는다.
- 문구 예시: "isolated single game asset, 2:1 isometric, fixed parallel projection, deep burgundy (#6B2427) hand-ink outline, flat warm pastel colors, no cast shadow, no text, transparent or flat magenta background, same style as reference"
- 같은 종류를 여러 장 만들 땐 크기·각도를 맞추기 위해 같은 문구에 색만 바꿔 요청한다.
- 받은 이미지는 제가 기준점·여백·크기를 맞추고 배경을 지워 게임에 넣는다. 각도나 선 굵기가 크게 다르면 다시 요청드린다.

## 5. 넘겨주는 방법
- `assets/` 폴더 구조대로 묶어서 올려 주면 된다. 이름이 규칙과 다르면 목록표(엑셀이나 메모)로 "파일 → 무엇인지·발판·방향"만 적어 줘도 된다.
- 엔진 쪽은 받는 대로 다음을 만든다: 이미지 불러오기와 묶음(아틀라스), 기준점 표(`assets/manifest.json`), 없는 이미지는 코드 그림으로 대신 그리기, 밤·눈·영업 층 겹치기, 사람 애니메이션 재생.
