# 모락모락 타운

작은 가게 하나로 시작해 직원을 키우고, 공간을 꾸미고, 뜨는 동네를 찾아 프랜차이즈를 늘리고 코스닥에 상장하는 힐링 경영 게임입니다.
도시 건설과 비즈니스 시뮬레이션 장르를 참고한 오리지널 게임이며, 빌드 도구나 외부 라이브러리 없이 브라우저에서 바로 실행됩니다.

## 그림체

선으로만 그린 카툰 아이콘(`js/icons.js`)과 얇은 선의 단순한 UI를 씁니다. 건물은 망사르드·박공지붕, 지붕창과 굴뚝, 자갈 포장 길과 랜턴 가로등이 있는 유럽풍 소도시입니다. 확대하면 매장 지붕이 걷혀 안이 보이고, 길을 걷던 손님이 실제로 문으로 들어갔다가 컵을 들고 나옵니다. 거리에는 산책·러닝·출근하는 사람, 공원 벤치와 잔디, 해변의 선베드에서 쉬는 사람이 있습니다.

진한 자주색 잉크 외곽선과 납작하고 따뜻한 색면(먼지 낀 분홍, 겨자, 라벤더, 산호, 세이지)을 쓰는 아이소메트릭 선화 스타일입니다. 건물에는 크림색 창틀과 꽃상자, 지붕선 물결 장식, 현관 계단, 옥상의 화분과 선베드가 있고, 거리에는 보도블록과 횡단보도, 가로등, 달리는 자동차와 택시, 배달 오토바이, 산책하는 사람과 강아지, 지붕 위 비둘기가 있습니다. 화면 아래에는 동그란 크림색 배지 도구가 놓입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 진행 상황은 매달 1일과 창을 닫을 때 브라우저 저장소(localStorage, `morak.save.v5`)에 저장됩니다.

조작: 드래그로 지도 이동, 휠·핀치로 확대, 매장 두 번 클릭으로 매장 안 들어가기, `Space` 일시정지, `1`·`2`·`3` 속도(하루 1분·3배·10배), `Esc` 닫기.

## 시간

1스텝이 1시간인 24시간 시계로 돌아갑니다. 2027년 3월 1일(월) 오전 6시에 시작하며 실제 달력·요일·공휴일·명절을 씁니다. 1배속은 게임 1시간이 2.5초, 하루가 1분입니다. 우리 매장이 모두 문을 닫은 밤에는 자동으로 빨리 감습니다. 지도는 시간에 따라 새벽·낮·노을·밤으로 바뀌고, 밤에는 가로등과 영업 중인 매장에 불이 켜집니다.

## 소리

음원 파일 없이 Web Audio로 직접 만듭니다. 배경 음악은 오르골 같은 종소리 선율과 부드러운 화음이 매번 조금씩 다르게 흘러가고, 아침·저녁·밤에 따라 빠르기와 화성이 바뀝니다. 비나 눈이 오면 빗소리가 깔립니다. 효과음은 버튼, 건설, 동전, 채용 종소리, 매장 문 풍경, 목표 달성 팡파르, 좋은 소식 알림이 있습니다. 상단 🎵·🔔 버튼으로 켜고 끄며 설정은 브라우저에 기억됩니다. 브라우저 정책상 화면을 한 번 누른 뒤부터 소리가 납니다.

## 파일

- `js/icons.js` — 선 아이콘 모음. 화면의 이모지를 자동으로 아이콘으로 바꾸고 캔버스에도 같은 아이콘을 그립니다.
- `js/sim.js` — 시뮬레이션 코어. DOM 없이 Node에서도 돌아가며, 같은 시드면 같은 결과가 나옵니다.
- `js/render.js` — 도시와 매장 내부를 그리는 캔버스 렌더러.
- `js/audio.js` — 배경 음악과 효과음.
- `js/ui.js` — 패널, 매장 안 화면(운영·메뉴·직원·인테리어·건물·기록), 입력, 게임 루프, 저장.
- `test/sim.test.cjs` — `node games/morak-town/test/sim.test.cjs`. 달력, 2년 자동 진행, 직원 능력치·인테리어·건물의 효과, 확장·가맹·상장, 저장/불러오기, 인수 합병을 점검합니다.

이 폴더는 저장소의 주식 앱(`partisan_investment.html` 등)과 독립적이며 서로 파일을 공유하지 않습니다.
