# 모락모락 타운

작은 가게 하나로 시작해 프랜차이즈를 키우고 주식시장에 상장하는 힐링 경영 게임입니다.
도시 건설과 비즈니스 시뮬레이션 장르를 참고한 오리지널 게임이며, 빌드 도구나 외부 라이브러리 없이 브라우저에서 바로 실행됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 진행 상황은 매달 자동으로 브라우저 저장소(localStorage)에 저장되고, 회사 탭의 "지금 저장"으로 직접 저장할 수도 있습니다.

조작: 드래그로 지도 이동, 휠·핀치로 확대, `Space` 일시정지, `1`·`2`·`3` 속도, `Esc` 도구 해제, 오른쪽 클릭으로 건설 취소.

## 게임 내용

| 영역 | 내용 |
| --- | --- |
| 도시 | 33×33 아이소메트릭 도시. 업무지구·대학가·주택가·호수 공원 네 구역마다 손님 유형(직장인·대학생·주민·관광객)과 가격 민감도가 다릅니다. 매달 빈 땅이 개발되고 건물이 자랍니다. 공원과 버스정류장을 기부하면 주변이 더 빨리 성장합니다. 사계절에 따라 풍경과 업종별 수요가 바뀝니다. |
| 매장 | 카페·베이커리·국수집·버거·디저트. 업종을 고르면 지도에 예상 손님이 많은 자리가 초록색으로 표시됩니다. 매장별로 가격, 직원(자동/수동), 홍보 단계, 확장(Lv.3까지), 건물 매입을 조정합니다. 수용 인원을 넘는 손님은 돌아가고 평점이 떨어집니다. |
| 물류 | 직송은 원가 +12%. 물류창고(반경 8칸, -15%)와 중앙주방(음식 -21%, 품질 +10%)이 매장에 식자재를 배송하고 트럭이 실제 도로를 따라 움직입니다. 로스터리(원두 -35%), 협력 농장 계약(고기·채소 -15%). 식자재 시세는 매일 변하고 급등·풍작 사건이 일어납니다. |
| 브랜드·가맹 | 업종별 인지도는 손님과 홍보로 오르고 서서히 줄어듭니다. 레시피 연구(Lv.10까지)와 광고 캠페인. 직영 3곳·인지도 20이면 가맹 모집 가능. 로열티가 낮을수록 지원자가 많고, 장기 적자 가맹점은 폐업하며 브랜드에 흠이 납니다. |
| 주식 | 매장 8곳·기업가치 30억·석 달 연속 흑자면 상장(신주 30% 공모). 주가는 순이익·성장률·인지도·배당으로 계산한 적정가를 따라 움직입니다. 유상증자, 자사주 매입, 배당 성향 조절. 경쟁사 지분을 50% 넘게 사면 인수 합병할 수 있습니다. |
| 경쟁사 | 구름커피·보리밭베이커리·한그릇푸드. 같은 수요 모델로 입지를 고르고, 가격을 맞대응하고, 적자 매장을 닫고, 연구·광고를 합니다. |
| 목표 | 첫 매장부터 시가총액 1,000억원까지 11단계. 일부는 보상금이 있습니다. |

## 파일

- `js/sim.js` — 시뮬레이션 코어. DOM이 없어 Node에서도 돌아가며, 시드 고정 난수를 써서 같은 시드면 같은 결과가 나옵니다.
- `js/render.js` — 캔버스 아이소메트릭 렌더러(건물, 계절 나무·입자, 보행자, 배송 트럭, 구름).
- `js/ui.js` — 패널, 정보 카드, 입력, 게임 루프, 저장.
- `test/sim.test.cjs` — `node games/morak-town/test/sim.test.cjs`. 2~3년 자동 진행으로 숫자 깨짐, 경쟁사 매장 상한, 확장·가맹·상장 흐름, 저장/불러오기, 인수 합병을 점검합니다.

이 폴더는 저장소의 주식 앱(`partisan_investment.html` 등)과 독립적이며 서로 파일을 공유하지 않습니다.
