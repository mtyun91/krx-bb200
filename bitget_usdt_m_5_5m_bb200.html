Bitget 무기한 선물 API 발급 및 연결 방법 (3단계) USDT-M Perp
  1. Bitget API 키 발급: Bitget 로그인 → 우측 상단 프로필 → [API Keys] → [Create API Key] → System-generated 선택 후 Passphrase(비밀번호) 지정
  2. 선물 양방향 권한 체크: 권한(Permissions)에서 반드시 [Futures - Orders / Holdings (선물 주문 및 포지션)] Read-Write를 체크 (출금 Withdraw 권한은 보안을 위해 해제)
  3. 권장: 로컬 브릿지 — 이 HTML과 같은 폴더의 bitget_bridge.py를 실행하면 키는 PC 환경변수에만 있고 브라우저에는 저장되지 않습니다. 실행 창에 표시되는 브릿지 토큰을 오른쪽에 입력 후 [연결]을 누르세요.
  4. 직접 연결(HMAC)은 키를 브라우저 메모리에 두며, Bitget이 브라우저 직접 호출을 막으면(CORS) 동작하지 않습니다. 키는 저장되지 않아 새로고침 시 다시 입력해야 합니다.

⚠ API 생성 시 출금(Withdraw) 권한은 반드시 끄고, 가능하면 IP 화이트리스트를 설정하세요.

레버리지 수수료 차감 공식 (Bitget USDT-M 선물 기준)

• 선물 수수료는 내 원금이 아니라 레버리지가 곱해진 총 포지션 규모(Notional Value)에 부과됩니다.
• 예: 5배로 시장가 진입·청산(편도 0.06% + 슬리피지 0.02%) 시 (0.08% + 0.08%) × 5배 = 0.80% 차감
• 목표가·50% 분할 익절은 지정가(Maker)로, 손절·트레일링·중심선 청산은 시장가로 계산합니다.
• 펀딩비는 실제 정산 시각(UTC 00·08·16시)에 포지션을 보유 중일 때만, 방향에 맞게(롱 지불/숏 수취) 반영합니다.
• 순수익률 = Σ(물량비중 × 가격변동 × 레버리지) − 수수료 − 펀딩 (1·2·3차 전체 계획 증거금 대비)
